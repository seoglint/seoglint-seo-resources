# Contributing

Thanks for helping keep these examples accurate.

## What we accept

- Corrections backed by official documentation (Google Search Central, schema.org, a crawler operator's own docs)
- Updates when a provider renames, adds, or retires a crawler
- New examples that are useful on their own and follow the style of this repository

## What we don't accept

- Promotional links or affiliate links
- Claims that a technique guarantees rankings, rich results, or AI citations
- Markup that describes things that aren't on the page (fake reviews, ratings, or prices)

## How to submit

1. Open an issue describing the problem, with a link to the source.
2. Or open a pull request. Run `python3 scripts/validate.py` first and make sure it ends with `All checks passed.`
3. Keep the "Last verified" date in the folder README up to date if you change facts.

## Code of conduct

Be respectful. Disagreements about SEO should be settled with sources, not opinions.
